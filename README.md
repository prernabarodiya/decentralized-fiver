# Decentralized-fiver


# 🚀 DFiver: Blockchain Integrated Crowdsourced Task Management System

DFiver is a full-stack decentralized crowdsourced task management platform inspired by Fiverr, enhanced with blockchain technology using **Solana Devnet**. It enables secure task creation, participation, verification, and reward distribution using wallet-based authentication and smart contract interactions.

---

## 🌟 Features

- 👤 **Dual Role System** (User & Worker dashboards)
- 📝 Create and manage microtasks (image selection, labeling, categorization)
- 🧑‍💻 Workers can browse and submit task responses
- 🔐 **Phantom Wallet Authentication** (no passwords required)
- ⛓️ Blockchain-based reward distribution using Solana Devnet
- 📦 Secure image file uploads using AWS S3
- ⚡ Real-time task submission and verification flow

---

## 🧱 System Architecture

- **Frontend 1 (User Panel):** Task creation and management
- **Frontend 2 (Worker Panel):** Task browsing and submission
- **Backend:** Node.js + Express API server
- **Blockchain Layer:** Solana Devnet (Web3.js + Wallet Adapter)
- **Database:** PostgreSQL (Prisma ORM)
- **Storage:** AWS S3
